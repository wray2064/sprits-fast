# Keyboard shortcuts

These are the defaults. Every one can be changed in **Edit > Preferences... > Keys**, and **Help > Keyboard shortcuts**
always shows what the keys are *now*, including your changes. `Ctrl+Shift+P` searches every command by name.

## Tools

| Key | Tool |
|---|---|
| `B` | Pencil |
| `Shift+B` | Spray |
| `E` | Eraser |
| `G` | Fill |
| `Shift+G` | Gradient |
| `I` | Pick colour |
| `R` | Rectangle |
| `U` | Ellipse |
| `L` | Line |
| `D` | Contour |
| `Shift+D` | Polygon |
| `Shift+L` | Curve |
| `Shift+T` | Text |
| `M` | Rectangle marquee |
| `Shift+M` | Ellipse marquee |
| `Q` | Lasso |
| `Shift+Q` | Polygon lasso |
| `W` | Magic wand |
| `C` | Slice |
| `V` | Move |
| `H` | Hand (or hold `Space`) |
| `Z` | Zoom |

## Brush and colour

| Key | |
|---|---|
| `Shift+]` / `Shift+[` | Brush larger / smaller |
| `X` | Swap the two colours |
| `Ctrl+P` | Next palette |
| `Ctrl+B` | Brush from selection |

## File

| Key | |
|---|---|
| `Ctrl+N` | New |
| `Ctrl+O` | Open |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save as |
| `Ctrl+Shift+E` | Export again |
| `Ctrl+L` | Library |
| `Ctrl+W` | Close tab |
| `Ctrl+Q` | Quit |

## Edit and selection

| Key | |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Redo |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Cut, copy, paste |
| `Ctrl+Shift+V` | Paste as new layer |
| `Ctrl+A` | Select all |
| `Ctrl+D` | Deselect |
| `Ctrl+Shift+I` | Invert selection |
| `Shift+H` / `Shift+V` | Flip the selection horizontally / vertically |

## Layers

| Key | |
|---|---|
| `Ctrl+J` | Duplicate layer |
| `Ctrl+E` | Merge down |
| `Ctrl+G` | Group layers |
| `Ctrl+Shift+G` | Ungroup |
| `Ctrl+]` / `Ctrl+[` | Raise / lower layer |

## Animation

| Key | |
|---|---|
| `Enter` | Play or stop |
| `,` / `.` | Previous / next frame |
| `O` | Onion skin |
| `Ctrl+Shift+D` | Duplicate frame |
| `T` | Timeline: open or tuck it (or show and hide it when pinned) |

## View

| Key | |
|---|---|
| `]` or `Ctrl+=` | Zoom in |
| `[` or `Ctrl+-` | Zoom out |
| `Ctrl+0` | Fit to window |
| `Shift+S` | Snap to grid |
| `P` | Preview |
| `Shift+R` | References |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Next / previous tab |

## Help

| Key | |
|---|---|
| `F1` | This guide |
| `Ctrl+Shift+P` | Search commands |

## In the middle of something

| Key | |
|---|---|
| `Space`+drag | Pan (or the middle button) |
| `Shift`+click | A straight line from the last stroke |
| `Shift` while dragging | Square rectangle, round ellipse, 15-degree line |
| `Alt` while dragging a reference | Move the reference |
| `Esc` while dragging a gizmo | Put it back |
