# Atajos de teclado

Estos son los predeterminados. Todos se pueden cambiar en **Editar > Preferencias... > Teclas**, y
**Ayuda > Atajos de teclado** muestra siempre cuáles son las teclas *ahora*, incluidos tus cambios.
`Ctrl+Shift+P` busca cualquier comando por nombre.

## Herramientas

| Tecla | Herramienta |
|---|---|
| `B` | Lápiz |
| `Shift+B` | Aerógrafo |
| `E` | Borrador |
| `G` | Relleno |
| `Shift+G` | Degradado |
| `I` | Cuentagotas |
| `R` | Rectángulo |
| `U` | Elipse |
| `L` | Línea |
| `D` | Contorno |
| `Shift+D` | Polígono |
| `Shift+L` | Curva |
| `Shift+T` | Texto |
| `M` | Marco rectangular |
| `Shift+M` | Marco elíptico |
| `Q` | Lazo |
| `Shift+Q` | Lazo poligonal |
| `W` | Varita mágica |
| `C` | Corte |
| `V` | Mover |
| `H` | Mano (o mantén `Espacio`) |
| `Z` | Zoom |

## Pincel y color

| Tecla | |
|---|---|
| `Shift+]` / `Shift+[` | Pincel más grande / más pequeño |
| `X` | Intercambiar los dos colores |
| `Ctrl+P` | Paleta siguiente |
| `Ctrl+B` | Pincel desde la selección |

## Archivo

| Tecla | |
|---|---|
| `Ctrl+N` | Nuevo |
| `Ctrl+O` | Abrir |
| `Ctrl+S` | Guardar |
| `Ctrl+Shift+S` | Guardar como |
| `Ctrl+Shift+E` | Exportar de nuevo |
| `Ctrl+L` | Biblioteca |
| `Ctrl+W` | Cerrar pestaña |
| `Ctrl+Q` | Salir |

## Edición y selección

| Tecla | |
|---|---|
| `Ctrl+Z` | Deshacer |
| `Ctrl+Shift+Z`, `Ctrl+Y` | Rehacer |
| `Ctrl+X`, `Ctrl+C`, `Ctrl+V` | Cortar, copiar, pegar |
| `Ctrl+Shift+V` | Pegar como capa nueva |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+D` | Deseleccionar |
| `Ctrl+Shift+I` | Invertir selección |
| `Shift+H` / `Shift+V` | Voltear la selección horizontal / verticalmente |

## Capas

| Tecla | |
|---|---|
| `Ctrl+J` | Duplicar capa |
| `Ctrl+E` | Combinar hacia abajo |
| `Ctrl+G` | Agrupar capas |
| `Ctrl+Shift+G` | Desagrupar |
| `Ctrl+]` / `Ctrl+[` | Subir / bajar la capa |

## Animación

| Tecla | |
|---|---|
| `Intro` | Reproducir o detener |
| `,` / `.` | Fotograma anterior / siguiente |
| `O` | Papel cebolla |
| `Ctrl+Shift+D` | Duplicar fotograma |
| `T` | Línea de tiempo: abrirla o esconderla (o mostrarla y ocultarla si está fijada) |

## Ver

| Tecla | |
|---|---|
| `]` o `Ctrl+=` | Acercar |
| `[` o `Ctrl+-` | Alejar |
| `Ctrl+0` | Ajustar a la ventana |
| `Shift+S` | Ajustar a la cuadrícula |
| `P` | Vista previa |
| `Shift+R` | Referencias |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Pestaña siguiente / anterior |

## Ayuda

| Tecla | |
|---|---|
| `F1` | Esta guía |
| `Ctrl+Shift+P` | Buscar comandos |

## En mitad de algo

| Tecla | |
|---|---|
| `Espacio`+arrastrar | Desplazar la vista (o el botón central) |
| `Shift`+clic | Una línea recta desde el último trazo |
| `Shift` al arrastrar | Rectángulo cuadrado, elipse redonda, línea a 15 grados |
| `Alt` al arrastrar una referencia | Mover la referencia |
| `Esc` al arrastrar un control | Dejarlo como estaba |
