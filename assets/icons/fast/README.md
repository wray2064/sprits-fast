# Icons drawn for Sprit's'fast

The seven icons here (`folder-open`, `sheet`, `images`, `book`, `bulb`, `keyboard`,
`file-plus`) were drawn for this program, in the manner of the Lucide set beside them
(`../lucide/`): 24 x 24, strokes only, round caps. They are made only of rectangles,
lines and arcs, and are under the same Apache License 2.0 as the rest of Sprit's'fast.

They are read and drawn like the others (`app/vector_icon`, `theme::drawIcon`).
