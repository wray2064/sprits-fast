# The gallery: every screen of the program, in every built-in theme, at 100% and
# 150% interface size, as images -- so a change of look is judged by eye, in one
# pass, rather than screen by screen.
#
# Run it with tools\gallery.ps1, which runs this from a folder of its own (the
# images are written to the folder it runs in, named THEME_SIZE_SCREEN.png) and
# then tiles the themes of each screen into one contact sheet. By hand:
#
#     build-gui\sprits_fast.exe --script tests\gallery\gallery.txt
#
# It is not one of tests/ui's scripts because it writes some three hundred
# images; tests/ui/gallery_smoke.txt keeps its machinery (the loops, the theme
# and size words, a PNG named by both) under test with the rest.
