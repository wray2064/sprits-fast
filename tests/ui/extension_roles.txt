# What a program built on Fast adds to a theme: roles of its own, here three
# made-up ones (`demo-roles` registers them as an AppExtension would). They are
# resolved by the theme in force, listed in Preferences > Appearance beside
# Fast's, edited and repaired the same way, and kept in a theme file.
# A scripted run keeps its themes in ui_selftest_themes, not the person's settings.
demo-roles
expect theme slate

# Slate is dark, so the dark defaults; Paper is light, so the light ones. A tint
# keeps its opacity.
expect colour demo.mark ff82c8
expect colour demo.label bedcff
expect colour demo.tint 78c8ff5a
theme paper
wait 2
expect colour demo.mark aa006e
expect colour demo.tint 0050c846
theme slate
wait 2

# They are in Preferences > Appearance, under the name their program gave them,
# below Fast's own roles.
click-on Edit
click-on Preferences...
wait 2
click-on Appearance
wait 2
expect missing Sample program
wheel -60
wait 2
expect item Sample program
wheel 60
wait 2

# A role changed is an edit of the theme, shown at once, and says so.
role demo.mark 33cc66
wait 3
expect colour demo.mark 33cc66
expect item Save as new theme
expect item Discard changes

# One that cannot be seen is flagged with the others, and Fix them moves it.
role demo.mark 1d2229
wait 3
wheel -4
wait 2
expect item Fix them
click-on Fix them
wait 3
expect missing Fix them
wheel 60
wait 2

# Discarded: the default comes back.
click-on Discard changes
wait 3
expect colour demo.mark ff82c8
expect missing Save as new theme

# Kept in the theme's file with the rest, and read back from it.
role demo.mark 33cc66
wait 3
click-on ##themename
type Script Roles
click-on Save as new theme
wait 3
expect file ui_selftest_themes/script-roles.lstheme
theme paper
wait 2
expect colour demo.mark aa006e
theme script-roles
wait 2
expect colour demo.mark 33cc66

# Escape puts the Preferences window away.
key escape
wait 3
expect missing Appearance

remove ui_selftest_themes/script-roles.lstheme
