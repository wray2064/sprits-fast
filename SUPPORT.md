# Support

## Help inside the program

**Help > User guide** is a searchable guide to everything the program does, with no
network needed. **Help > Keyboard shortcuts** lists every key (and lets you change
it), and **Help > Search commands** (`Ctrl+Shift+P`) finds a command by a few letters.

## Something is wrong

Open an issue at <https://github.com/wray2064/sprits-fast/issues>. The most useful
report says:

1. what you did, in steps, and what you expected;
2. what happened instead (a screenshot helps);
3. the version, from **Help > About**, and your Windows version;
4. a sprite that shows it, if it is about one (attach the `.lsprite`).

**Lost work**: if the program closed unexpectedly, start it again; it offers the
recovery copy it kept. If that does not appear, the copies are in the `SpritsFast`
folder of your user profile (the Store version: in the app's own storage).

## Asking for something

The same place. Say what you are trying to make; the reason is more useful than the
feature you think it needs.

## Privacy

See [PRIVACY.md](PRIVACY.md): the program collects nothing and never connects to the
internet.
