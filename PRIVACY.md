# Privacy policy

*Sprit's'fast, version 1.0. Last changed 2026-10-19.*

**Sprit's'fast does not collect, send or share any information about you or your
work.** It has no account, no sign-in, no analytics, no advertising and no crash
reporting. It contains no code that connects to the internet.

## What stays on your computer

The program keeps a few things, only on your own computer, only so that it can work
the way you left it:

- **Your settings**: preferences, key bindings, your own themes and saved layouts,
  the list of recent files and recent colours, and the interface language. In a
  folder named `SpritsFast` in your user profile (for the Microsoft Store version,
  Windows keeps it inside the app's own storage and removes it when you uninstall).
- **Recovery copies**: while you work, the program saves a copy of unsaved work
  to the same folder so that a crash or a power cut does not lose it. A copy is
  deleted when you save or discard the work.
- **Your files**: the sprites, images and exports you choose to open or write. The
  program reads and writes only the files and folders you pick (and the Library
  folders you set), and nothing else.

None of it is ever sent anywhere. To remove it, delete that folder, or uninstall.

## Links

The About window and the Help menu have links (the project page, where to report a
problem). Clicking one asks Windows to open it in your web browser; the program sends
nothing itself. What that website does is governed by its own policy.

## Children

The program asks for no personal information from anyone, of any age.

## Changes

If this ever changed -- it is meant not to -- the new policy would be published here
before a version that depends on it, and the change would be listed in the change log.
